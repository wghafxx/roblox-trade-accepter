# Бот автопринятия кейсов (ТЕСТ)

Бот сидит на компе с открытой игрой (Trade Plaza, акк-приёмщик) и сам кликает:
уведомление → список → сверка ника → accept → ждёт кейсы → проверяет → accept → готово.

**Сейчас ТЕСТ-РЕЖИМ: сайт не трогаем, RAP никому не начисляем.**
Успех = строка в консоли `ПРИНЯТО! total=N (TEST: без зачисления)`.
Сайт и зачисление прикрутим вторым шагом, когда примешь механику кликов.

## Что нужно на ПК

1. Windows 10/11, Python 3.11+ (с галочкой Add to PATH).
2. Игра открыта на весь экран, лучше 1920x1080, акк-приёмщик стоит на Trade Plaza.
3. Tesseract OCR: https://github.com/UB-Mannheim/tesseract/wiki → скачать installer,
   при установке добавить русский не надо, хватит English. Путь к `tesseract.exe`
   вписать в `config.yaml` (`tesseract_cmd`), либо добавить в PATH.
4. Консоль в папке `tradebot`:
```
pip install -r requirements.txt
copy config.example.yaml config.yaml
python calibrate.py
```

## Калибровка (важно!)

`calibrate.py` по шагам попросит обвести кнопки и области прямо на скринах
твоей игры. Делай аккуратно — от этого зависит, найдёт ли бот кнопки:
шаблоны кнопок обводи ВПРИТЫК, без фона.

В `config.yaml` впиши свой тестовый ник в `only_nicks` (без @) —
бот будет принимать ТОЛЬКО его, остальных decline. Со вторым своим акком
и кидай себе кейсы для теста.

## Запуск

```
python bot.py
```

Не трогай мышь, пока бот кликает. Остановка — Ctrl+C. Все действия пишутся
в консоль и в `bot.log`.

## Правила приёмки (как ты сказал)

- Ник есть в списке → ACCEPT, нет → DECLINE.
- Наша сторона должна быть пустой (Total RAP: 0), иначе DECLINE + тревога в лог.
- Каждый предмет: RAP из списка 66/65/44/43/42, иначе DECLINE.
- Предметов не больше 6, только первая страница (1/1), сумма от 35 RAP.
- Кнопка ACCEPT жмётся только если суммы не менялись 4 секунды (кд кнопки).
- Сомнение = DECLINE. Отклонённого игрока не баним — он может кинуть трейд заново.

## Чего тут нет (второй шаг)

Сверки ника с заявками сайта, автозачисления RAP, кнопки в админке.
Когда тест примешь — добавлю `site.py` + 3 ручки на сайте
(pending / settle / decline) и бот будет закрывать заявки сам.
